# The Immediate Neighborhood / Ближайшие окрестности

Интерактивная трёхмерная визуализация ближайшего звёздного окружения Солнечной системы в радиусе **15 световых лет**.

Interactive 3D visualization of the stellar neighborhood within 15 light-years of the Sun.

## 🌟 Возможности / Features

- **3D-визуализация** всех звёздных систем в радиусе 15 световых лет от Солнца
- **Свободная навигация** — вращение, масштабирование, панорамирование
- **Научно обоснованные цвета** спектральных классов (O, B, A, F, G, K, M) по Harre & Heller (2021)
- **Визуальные размеры** звёзд качественно соответствуют их реальным радиусам
- **Интерактивные попапы** с информацией о каждой звезде
- **Двуязычный интерфейс** (EN/RU)
- **Адаптивный дизайн** для десктопных и мобильных устройств

## 📊 Данные / Data

Данные о звёздах получены из авторитетных астрономических каталогов:
- **RECONS** (Research Consortium on Nearby Stars)
- **Gaia DR3** (уточнённые параллаксы)
- **Hipparcos** (для ярких звёзд)

### Структура данных

Каждая звезда содержит:
- Название (популярное и каталожное)
- Спектральный класс
- Расстояние от Солнца (св. лет)
- Экваториальные координаты (RA/Dec)
- Радиус (в радиусах Солнца)
- Светимость (в солнечных единицах)
- Цвет (на основе спектрального класса)

### Преобразование координат

Экваториальные координаты (RA, Dec) и расстояние преобразуются в декартовы координаты:
```
x = d × cos(dec) × cos(ra)
y = d × cos(dec) × sin(ra)
z = d × sin(dec)
```

## 🎨 Цвета спектральных классов

Цвета основаны на исследовании Harre & Heller (2021):

| Класс | Цвет | Описание |
|-------|------|----------|
| O | #9bb0ff | Голубой |
| B | #aabfff | Голубовато-белый |
| A | #cad7ff | Белый |
| F | #f8f7ff | Желтовато-белый |
| G | #fff4ea | Жёлтый |
| K | #ffd2a1 | Оранжевый |
| M | #ffb56b | Красно-оранжевый |

> **Важно:** Красные карлики (M) отображаются как оранжевые, а не ярко-красные, что соответствует их реальному цвету при наблюдении.

## 📐 Масштабирование размеров

Из-за огромной разницы в размерах звёзд (от ~0.1 R☉ для красных карликов до ~2 R☉ для субгигантов) используется **качественная шкала размеров**:

| Радиус (R☉) | Визуальный размер |
|-------------|-------------------|
| ≥ 1.5 | Крупный (гиганты) |
| ≥ 1.0 | Средний (солнцеподобные) |
| ≥ 0.5 | Средне-малый |
| ≥ 0.3 | Малый |
| ≥ 0.15 | Маленький (карлики) |
| < 0.15 | Минимальный |
